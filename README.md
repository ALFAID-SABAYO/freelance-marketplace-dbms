# Freelance Marketplace (DBMS Project)

A database-driven freelance marketplace built with PostgreSQL that manages clients, freelancers, job postings and bids. It includes a dashboard with charts that show platform activity and trends.

## Features
- Client and freelancer profile management
- Job posting and bid submission system
- View freelancer bids on available jobs
- Dashboard with graphs showing platform data and trends

## Tech Stack
- Database: PostgreSQL
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js
- Visualization: Chart.js
